# Face Recognition Attendance System

## 📌 Overview

A Face Recognition Attendance System developed using **Python**, **Flask**, and **OpenCV** to automate attendance by recognizing registered faces in real time.

> **Academic Team Project** completed as part of the Third-Year B.Tech Computer Engineering curriculum.

---

## 🚀 Features

- Face Registration
- Face Encoding & Training
- Real-time Face Recognition
- Automatic Attendance Marking
- Student Management
- Attendance Records
- Flask-based Web Interface

---

## 🛠️ Technologies Used

- Python
- Flask
- OpenCV
- face_recognition
- HTML
- CSS
- JavaScript
- SQLite

---

## ▶️ How to Run

1. Clone the repository.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Start the application:

```bash
python app.py
```
